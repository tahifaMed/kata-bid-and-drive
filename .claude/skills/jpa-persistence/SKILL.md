# JPA and persistence

- Keep JPA entities in `adapter.out.persistence`. Map them to and from domain objects in a mapper. Never expose them through a controller.
- Schema changes go through Flyway only: `src/main/resources/db/migration/V<n>__<description>.sql`. Never edit a migration that has been merged. Add a new one.
- Hibernate `ddl-auto` is `validate` outside tests.
- Optimistic locking: every aggregate that takes concurrent writes has a `@Version` column. A conflict maps to HTTP 409.
- Fetch lazily by default. Use `@EntityGraph` or a projection for read endpoints. Avoid `FetchType.EAGER`.
- Keep `BigDecimal` columns at `numeric(19,2)`.
- Use IDs generated by the application (UUID) for aggregates, so domain code can create them without a round trip.
